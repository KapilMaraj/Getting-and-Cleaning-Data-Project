This repository contains the R code and documentation for the Coursera Getting and Cleaning Data Course Project.

The data used for this project is the **Human Activity Recognition Using Smartphones Dataset**. 

* `run_analysis.R`: The R script that performs the data preparation, cleaning, and analysis.
* `FinalData.txt`: The final tidy dataset exported from the script containing the averages of variables.
* `CodeBook.md`: A document describing the variables, the data, and the transformations performed.

1. Download and unzip the data from [UCI HAR Dataset](http://archive.ics.uci.edu/ml/datasets/Human+Activity+Recognition+Using+Smartphones).
2. Set your R working directory to the folder containing the unzipped `UCI HAR Dataset` folder.
3. Run the `run_analysis.R` script in R or RStudio.
4. The script will generate a file named `FinalData.txt` in your working directory.
